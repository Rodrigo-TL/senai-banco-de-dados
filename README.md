# 🛡️ SENAI - Banco de Dados (Projeto RPG Online)

Este repositório contém as resoluções e scripts desenvolvidos durante as atividades práticas de Banco de Dados do SENAI.

## 🗂️ Arquivos do Projeto

*   **`Avaliacao_02_RPG.sql`**: Script de definição de dados (DDL) responsável pela criação do banco de dados `JogoRpgDB` e das 5 tabelas do jogo (`USUARIOS`, `CLASSES`, `HABILIDADES`, `PERSONAGENS` e `CLASSES_HABILIDADES`).
*   **`Avaliacao_03_DML.sql`**: Script de manipulação de dados (DML) contendo a inserção de registros de exemplo, testes de atualização (`UPDATE`), exclusão (`DELETE`) e consultas fundamentais (`SELECT`).
*   **`Avaliacao_04_Seguranca.sql`**: Configurações de segurança e governança, aplicando controle de acesso restrito (usuário `aluno` apenas com permissão de leitura) e o recurso **SQL Server Audit** direcionado para a pasta local `C:\AuditoriaExemplo`.

## 🛠️ Tecnologias e Ferramentas
*   **SGBD:** Microsoft SQL Server 2022 Express Edition
*   **Interface:** SQL Server Management Studio (SSMS)
